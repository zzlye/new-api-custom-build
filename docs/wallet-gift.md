# 钱包与赠金

## 简介

赠金是可用余额的一部分，可以直接消费。可用总余额等于普通余额与赠金之和，不需要额外领取或转入。

## 如何使用

在钱包、个人资料和账户概览中查看赠金。管理员也可以在用户列表和用户详情中查看。

管理员打开用户的「调整额度」，选择「普通余额」或「赠金」，再选择增加、减少或覆盖，输入金额并确认。减少赠金时不会扣除普通余额，赠金不足时不会执行扣除。相关调整会记录在日志中。

## 功能介绍

- 邀请奖励、邀请充值返佣、注册赠送、被邀请奖励和签到奖励计入赠金。
- 在线充值与兑换码充值计入普通余额。
- 消费优先使用赠金，赠金用完后使用普通余额；余额购买订阅也遵循这个顺序。
- 请求退款按照原来的资金类别返还。部分退款优先返还普通余额，使最终消费仍优先使用赠金。
- 历史余额根据保留的奖励、消费和退款记录划分；缺失记录不补算，总余额不变。划分后的赠金不会超过当前非负总余额，也不会在重复启动时重复补入。
