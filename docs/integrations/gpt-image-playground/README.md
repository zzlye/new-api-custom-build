# New API 生图工具接入

## 简介

在 GPT Image Playground 中使用 New API 生成和编辑图片。普通使用保留原来的操作方式，无需导入自定义服务商配置。

New API 保留 QuantumNous 项目署名；GPT Image Playground 由 CookSleep 提供。

## 如何使用

1. 打开 GPT Image Playground，进入「设置 → API 配置」。
2. 服务商类型选择「OpenAI 兼容接口」，API 接口选择「Images API」。
3. 本机地址填写 `https://localhost:8443/v1`，模型填写 `gpt-image-2`；连接其他 New API 时，填写自己的地址和已开通的模型。
4. 在 API Key 中填写自己的 New API 令牌。对应渠道中的上游密钥应在 New API 渠道设置中填写，两者各有用途。
5. 在 New API 中确认模型价格已经设置；使用本地 HTTPS 前，确认浏览器信任的是本机创建的证书。
6. 正常提交生图并等待图片显示，也可以在 New API 的任务日志中查看进度和生成图片。

如果先前导入过「New API 本地异步」配置，普通使用时切回「OpenAI 兼容接口」即可。其他本来使用普通接入方式的生图工具无需调整。

只有确实需要提交后立刻获得任务编号时，才使用同目录的 `new-api-local-async.json`：复制完整内容，在自定义服务商管理中点击「从剪贴板粘贴并导入」，再填写自己的 New API 令牌。这是可选用法，普通生图不依赖它。

## 功能介绍

- 支持文本生图、参考图编辑和遮罩重绘。
- 提交后由后台继续处理，普通生图工具直接显示结果；支持实时预览的工具继续显示生成过程。
- 页面关闭或连接断开后，已提交的后台任务继续处理，结果可以在 New API 任务日志中查看。
- 视频保持原来的使用方式，后台继续记录进度并保存生成文件。
- New API 中的生成文件默认保留两小时，具体时长由根用户设置。
- New API 的保留时长不影响用户已经下载或保存在生图工具中的图片。
