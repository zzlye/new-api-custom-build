# New API 生图工具接入

## 简介

使用这份配置，可以在 GPT Image Playground 中提交 New API 生图任务，查看处理进度，并在完成后看到图片。

New API 保留 QuantumNous 项目署名；GPT Image Playground 由 CookSleep 提供。

## 如何使用

1. 打开同目录的 `new-api-local-async.json`，复制文件的完整内容。
2. 打开 GPT Image Playground，在「设置 → API 配置」中打开自定义服务商管理，点击「从剪贴板粘贴并导入」。
3. 选择导入的「New API 本地异步」配置，在 API Key 中填入自己的 New API 令牌。导入文件不包含任何密钥。
4. 本机使用时，保留地址 `https://localhost:8443/v1` 和模型 `gpt-image-2`；连接其他 New API 时，填写自己的地址和已开通的模型。
5. 使用本地 HTTPS 前，确认浏览器信任的是本机创建的证书。如遇证书提示，先完成本机证书信任设置。
6. 在 New API 中确认模型价格已经设置，并在对应渠道中填写有效的上游密钥。生图工具使用的 New API 令牌与渠道中的上游密钥各有用途，请分别填写。
7. 提交生图后等待页面显示结果，也可以在 New API 的任务日志中查看进度和生成图片。

导入后请选择「New API（后台任务）」服务商，而不是原来的「OpenAI 兼容接口」或「sub2api（异步）」。后两项与这份 New API 接入配置不同。

## 功能介绍

- 支持文本生图、参考图编辑和遮罩重绘。
- 提交后由后台继续处理，生图工具自动查看进度并展示结果。
- 生成结果同时可以在 New API 任务日志中查看。
- New API 中的生成文件默认保留两小时，具体时长由根用户设置。
- New API 的保留时长不影响用户已经下载或保存在生图工具中的图片。
